ALSSA Brevity · 25 April 2025
来源：https://www.alssa.mil/Portals/9/Documents/mttps/brevity_2025.pdf
共628条中文简释。条目仅解释含义，不代表游戏已实现对应能力。

ABORT / 中止/终止
在释放武器或任务事件前，停止当前行动或终止攻击。

[High or Low] ACCURACY / [高或低]精度
定位时满足预 briefed 的标准；需由编队指挥官简报或在特殊指令中规定。

ACTION / 执行
发起已简报的攻击序列或机动动作（空对空、空对地、地对空、空地海）。

[system] ACTIVE [location, direction] / [系统]激活 [位置,方向]
引用的辐射源正在指定位置或沿指定方位辐射；源自电子情报。

ADD [system or category] / 增加 [系统或类别]
将特定系统或电磁战斗序列类别加入搜索职责。

[weapon] AFFIRM / [武器]确认
友军地对空武器平台准备攻击指定目标（如：BIRD(S) AFFIRM）；与否定相反。

ALARM / 警报
终止或正在终止发射控制程序；与休眠相反。

ALLIGATOR / 短吻鳄
Link-11A 或战术数据链 Alpha。

ALPHA CHECK / Alpha检查
请求确认飞机到描述点的方位和距离。

ANCHOR [location] / 锚点 [位置]
1. 围绕特定点盘旋。2. 加油机飞行的加油航线。

ANCHORED [location] / 锚定 [位置]
在指定位置进行的转向交战。

ANGELS / 高度
友军飞机相对于平均海平面的高度（以千英尺为单位）。

ANYFACE / ANYFACE
呼叫代号未知的友军指挥与控制机构。

ARIZONA / 亚利桑那
无反辐射导弹弹药剩余。

[direction] ARM / [方向]武装
单一编组内超出编组标准的接触目标机动。

AS FRAGGED / 按碎片指令
单位或单元将完全按照简报或计划执行。

ASLEEP / 睡眠
不再通过通信情报探测陆地或水面辐射源活动；与清醒相反。

ATTACK / 攻击
通知性呼叫，表明飞机正投入对特定地面目标的空对地投放；不用于近距空中支援。

AUTHENTICATE / 验证
请求或提供编码挑战的响应。

AUTOCAT / 自动中继
使用自动重传的通信中继。

AVALANCHE / 雪崩
通知性呼叫，表明友军部队在特定地点需要增援。

AWAKE / 清醒
通过通信情报检测到陆地或水面辐射源活动；与睡眠相反。

[number, weapon type] AWAY / [数量,武器类型] 发射
释放或发射指定武器；至少包含数量或武器类型；适当时包含公牛眼格式发射位置和弹道方向。

AZIMUTH / 方位角
1. 描述两个侧向分隔编组的标签，用基本方向命名。2. 威胁方向。

BAD MAP / 地图失效通报
因地形阴影遮挡或图像质量不足，导致显示地图无法使用，需更换轴位或掠射角获取新图。

BANDIT / 敌机/可疑目标
空战：按战区标准确认的敌方目标；太空：轨道参数可能威胁航天器的可疑目标。不隐含交战授权。

BANZAI / 自杀式突击
执行发射并决定战术，意图机动进入目视交战范围。

BASE [+/- number] / 基准数
用于指示航向、高度、燃油等数据的参考数值。

BAT(S) / 友军制导武器
具备多模导引头的联网滑翔武器，如防区外武器、精确制导炸弹或小直径炸弹。

BAY / 实施欺骗
电子战：执行既定或先前命令指示的欺骗计划。

BEAD WINDOW / 信息泄露警告
最后一次传输可能已泄露未经授权的信息。

BEAM [direction] / 侧舷方位
接触目标位于尾迹夹角60-109度或机头夹角71-120度范围内。

BEAM RIDER [direction] / 波束辐射源
沿指定方位存在潜在干扰源（地面单位或飞机），通常伴随请求使用替代雷达搜索。

[system] BENT / 系统故障
指定系统处于无效状态，由“SWEET”通报取消。

BERETTA / 弹药耗尽
飞机已用尽或无法使用剩余对地弹药，不包括机炮（如有配备）。

BIG STICK / 远程防空导弹
友军远程地对空导弹。修饰词包括远离、否定、确认。

BINGO / 最低返航油量
预 briefed 的用于恢复（返航）所需的燃油状态。

BIRD(S) / 防空导弹
友军地对空导弹。修饰词包括远离、否定、确认。

BIRDDOG / 传感器配置呼叫
按任务规划或简报配置传感器的呼叫。

BITTERSWEET / 误击风险通报
通知存在蓝对蓝（友军火力）或蓝对中性的潜在情况。

BLACKOUT / 关闭外部灯光/雷达饱和
空战：关闭所有外部灯光；海上：舰载雷达因过度饱和无法有效搜索或转换跟踪。

BLANK / 空白信号
信号正在发送但内容为零。

BLIND / 失去目视联系
与友军飞机、船只或地面位置无目视接触。与“VISUAL”相反。

BLOCK / 防御性阻挡机动
海军：通过直接 maneuvering 在接近 vessel 前方并保持位置，迫使其改变航向远离被保护资产或停止逼近，存在碰撞可能。

BLOTTER / 电磁对抗接收机
电子战：电磁对抗措施接收机。

BLOW(ING) THROUGH / 贯穿拦截
空战：在汇合点继续直线前进，不与目标锁定；或指移交瞄准责任并开始贯穿。

BLUR / 雷达受扰
雷达正在受到干扰。

BOGEY / 不明目标
身份未知的接触目标。

BOGEY DOPE / 敌情数据请求
请求提供最近或指定目标群相对于本机的方位、距离、高度和侧面位置信息。

BOOSTER / 助推器
识别为弹道导弹分离阶段的助推器组件轨迹。

BOX / 方格标识
用于在战术图中表示位于正方形或偏移正方形区域内的目标群标签。

BRAA / BRRA格式
按相对友机（方位、距离、高度、侧面）报告目标；或切换至该格式报告特定目标。

BRACKET [direction] / 包抄机动
向目标侧翼或垂直方向两侧机动，以占据有利攻击或防御位置。

BREAK [direction] / 紧急规避
立即向指定方向进行最大性能转弯（默认180度），通常用于脱离危险。

BREAK AWAY / 紧急脱离加油
加油机或受油机呼叫，要求立即进行垂直及前后方向的快速分离。

BROKEN SPUR / 无法接应撤离
表明直升机编队内相互支援或自行撤离不可行。

BROWNING / 导弹低电量
地空导弹平台处于导弹储备量低的告警状态。

BRUISER / 短程反舰攻击
使用友军空射亚音速短程反舰武器；需注明发射点及武器轨迹方向。

BUCKET / 区域雷达欺骗干扰
指控中心在指定地理区域内遭遇雷达电磁欺骗性干扰。

BUDDY [LASE or GUIDE] / 伙伴制导
请求或通报由非投弹飞机来源提供武器制导指引。

BUDDY LOCK [position, heading, altitude] / 伙伴雷达锁定
雷达锁定已知友机，通常作为对“被友机雷达锁定”呼叫的响应。

BUDDY SPIKE [position or heading or altitude] / 被友机雷达锁定
警告接收机显示友军系统雷达已对本机实施锁定。

BUGOUT [direction] / 撤离战场
从当前交战、攻击或行动中脱离，且无重新加入或返回意图。

BULLDOG / 水面/潜射反舰导弹
指代由友军水面舰艇或潜艇发射的反舰导弹。

BULLRING / 海上巡逻区
指定的海上飞机巡逻警戒区域。

BULLSEYE / 基准点
以此点为参照，通过磁方位角和海里距离确定其他物体位置的固定参考点。

BUMP / 功率微调
在当前动力设置基础上增加或减少功率输出。

BUSTER / 全速飞行
保持最大持续速度飞行。

BUTTON / 电台频道
无线电通信频道的设定状态。

BUZZER / 通信干扰
实施电磁通信干扰（同北约术语CHATTER）。

BUZZSAW / 照明弹标记
将化学荧光棒系绳上挥舞，用于标记友军阵地的信号装置。

CANDYGRAM / 电子战情报通告
通报在既定保密网络上可提供电子战目标信息。

CANYON / 峡谷干扰
按指定雷达频率或先前指令，执行电磁攻击以实施电子干扰。

CAP(PING) [location] / 建立空中巡逻
在指定地点建立战斗空中巡逻；或表示飞机已进入盘旋状态。

[target or object] CAPTURED / 捕获目标
目标已被传感器获取并正在跟踪中。

CATALOG / 登记信息
指示记录潜在目标的描述、位置和高度信息。

CEASE [activity] / 停止[活动]
立即停止指定的活动，如停止蜂鸣器、激光照射或闪光干扰。

CEASE ENGAGEMENT / 终止交战
命令防空单位停止对指定目标的战术行动；导弹将继续拦截但需准备应对新目标。

CEASE FIRE / 停止射击
禁止开火，已发射导弹继续拦截，需保持跟踪。

CHAMELEON / 变色龙
指已知频率但外部参数变化的电子战目标；不暗示授权攻击。

CHAMPAGNE / 香槟队形
由三组组成的队形：两前一组后。通常命名为南北或东西先导组及尾随组。

CHARLIE / 查理着陆
信号要求舰载降落；后缀数字表示预计延迟分钟数。

CHATTERMARK [comm type] / 开始防干扰通信
开始使用简报的通信程序以对抗通信干扰；未指明类型时默认为无线电。

CHEAPSHOT / 半程弹数据链中断
主动导弹数据链在未达到激活状态前即被终止。

CHECK [number, left or right] / 修正航向
向左或向右转弯指定度数并保持新航向。

CHECK CAPTURE / 丢失跟踪
目标似乎不再被传感器跟踪。

CHECK DATA [source] / 核查数据
参考指定媒介（如互联网中继聊天或Link-16自由文本）获取消息流量。

CHECK FIRE(ING) / 紧急停火
立即暂停直接和间接火力，可能需要协调才能恢复。

CHECK FOCUS / 失焦
传感器图像看起来处于失焦状态。

CHECKPRINT [track number] / 核查轨迹
空防指挥官请求单位提供指定轨迹的补充信息；或回复正解轨迹信息。

CHECK SOLUTION / 核查解算
观测到初始或齐射间误差过大时，观察员命令舰船检查火控解算。

CHECK TIDS / 核查TIDS
指示参考数据链路显示，可能随后附带补充信息。

CHERRY / 樱桃警告
通知进场飞机着陆区有超出预定风险容忍度的敌方活动；取消“冰块”指令。

CHERUBS / 天使高度
友机距地高度，单位为百英尺。

CHICK(S) / 小鸡
指代安全飞行或执行任务中的友机。

CHRISTMAS TREE / 圣诞树灯光
开启所有外部照明灯。

CLAM / 停止辐射
[电子战] 指示停止指定设备的信号发射；或通报当前干扰已停止，通常在“冷”状态下被默认接受。

CLEAN / 无接触/清洁
[空对空] 对感兴趣目标组无传感器信息；指飞机无可见战斗损伤；或指飞机未携带外挂武器。

CLEARED / 获准
请求的动作已获授权。注意：在空对空语境中，若支援角色未建立或未转移，则不自动适用。

CLEARED HOT / 获准开火
[空对地] 联合终端攻击控制员（JTAC）或前方空中管制员（FAC(A)）在类型1和2近距空中支援终端攻击控制中，授予攻击特定目标的武器释放许可。

CLEARED TO ENGAGE / 获准交战
[空对空/空对地] JTAC/FAC(A)在类型3控制下授予的攻击许可；或允许对指定目标组开火的指令。

CLIFF / 悬崖
[电子战] 指代干扰信号。

CLOAK(ING) / 隐身照明
从正常或显眼的外部灯光切换为仅兼容夜视设备的隐蔽照明模式。

CLOSING / 接近
[空对空] 两机之间的间隔正在减小。

CLOVER [left or right] / 三叶草机动
[空对地] 旋翼机指令，要求按指定方向（左或右）建立三叶草形状的飞行编队图案。

CLUSTER / 弹群
[地对空] 指在很小空间体积内的多枚弹道导弹物体聚集。

COLD / 冷
[空对空] 启动脱离预期威胁的巡逻转弯；截获几何构型将在目标后方通过或滚出。[空对地] 区域预计不会受到火力覆盖。[航空-海事] 接触方位稳定在尾后0-20度或鼻前160-180度。

COLOR [system, position] / 颜色查询
[电子战] 请求查询指定位置特定类型（系统）的信息，暗示要求解决身份歧义。可配合数据链消息使用。

COMEBACK [direction] / 折返
指令性呼叫，要求反向航向。

COME OFF [direction] / 脱离
[空对空] 按指示机动以恢复相互支援或解冲突径路，隐含目视发现和目标确认。[空对地] 执行机动或特定指令。

COMMIT / 投入
[空对空] 拦截感兴趣的目标组；或设定简报过的截获几何构型。

CONFIDENCE [level] / 置信度
根据作战指令提供的信心等级指示。

CONS/CONNING / 留迹
[空对空] 产生凝结尾迹的飞机。

CONTACT(S) / 接触点
在指定位置有传感器信息；[空对地] 确认 sighting 参考点；[空对空] 目标组或编队内的单个雷达回波。

CONTAINER / 容器队形
[空对空/航空-海事] 内部编队，由四个接触点组成正方形或偏移正方形的队形。

CONTINUE / 继续
继续当前机动，不隐含改变交战许可或弹药消耗状态。

CONTINUE DRY / 继续无弹药
[空对地] 继续当前机动，禁止投放弹药。用于批准飞机在不消耗弹药的情况下完成通场。模拟武器投放可能执行。

COVER / 掩护
[空对空/地对空] 分配防空武器或建立空战姿态以应对指定轨迹；[空对地] 准备重新攻击；[特种作战] 分配武器以应对威胁。

COVEY / 群集
[空对地/地对地] 两个或多个诱饵信号的组合。

CRANK [direction] / 曲率机动
[空对空] 按指示方向机动，隐含在雷达万向节极限处或附近照射目标。

CRATER [location] / 弹坑 [位置]
预期威胁弹道导弹的撞击点。

CREEP / 爬移
表征信号特征。

CRISS CROSS / 十字交叉
通过绘制测向方位线得出的位置或航迹。

CROSSING / 交叉
两个初始方位分离的编队，减小方位分离以相互通过。

CROW(S) / 乌鸦(s)
被拘留者或囚犯。

CRUISE / 巡航
返回巡航速度（在BUSTER或GATE之后）。

CURVE / 曲线
欺骗信号。

CUTOFF [direction] / 截断 [方向]
请求或指令使用截断几何进行拦截。

DAISY / 雏菊
通知信号特征在已验证参数范围内。

DARK STAR / 暗星
未能正确点亮的照明弹。

DASH [number] / 冲刺 [数字]
飞行中飞机的位置。若呼号未知时使用。

DATA [object, position] / 数据 [目标, 位置]
关于指定位置目标的数传消息。

[weapon] DAZZLE (ON/OFF) / [武器] 致盲 (开/关)
对目标进行压制性非致命射击，使其传感器性能低于完成使命所需水平。

DEADEYE / 死眼
激光指示器系统故障。

DECLARE / 声明
询问特定航迹、目标或关联编队的身份。回复可能包括：友军、敌机、强盗、敌对、中立、无法识别、干净或混战。回复需附带完整位置数据(BULLSEYE)或航迹编号。

DECLUTTER / 去杂波
1. 请求飞行员或操作员移除瞄准符号，以便更好地观察目标区域。2. 最小化屏幕图形，防止感兴趣的目标被遮挡。

DEEP / 深
表示三个或以上编队相对队形中最近和最远编队之间的距离，用于描述梯阵、V字、香槟或箱式队形。

DEFENDING [direction] / 防守 [方向]
飞机处于防御位置，并参照雷达威胁进行机动。

DEFENSIVE / 防御中
飞机遭受攻击，正在防御性机动，且无法确保冲突解脱或相互支援。

DELOUSE / 清尾
探测、识别并（如需要）交战跟随友军的未知平台。

DELTA [altitude] [position] / 三角洲 [高度] [位置]
舰载作业期间，在指定高度和位置保持并节约燃油。

DEPLOY / 部署
机动至简报中的定位点。

DETAILS / 细节
请求攻击或执行简报。

DIAMONDS [position] / 钻石 [位置]
地面红外事件的位置。

DIRT / DIRT
雷达警告接收机指示处于搜索模式的地面威胁信号。参见MUD和SINGER。

DIRTY / DIRTY
1.链路未加密。2.[空对空]飞机处于着陆构型。3.[空对空]飞机挂载外挂物（即“脏翼”）。

DIVERT / DIVERT
前往备降基地。

DOG [status] / DOG [状态]
[空对空][地对空]空投式诱饵。**(COLLARED):诱饵收起。** (LEASHED):诱饵伸出。** (SNIPPED):诱饵与飞机分离。

DONORIZE(D) / DONORIZE(D)
将飞机数据作为飞行编队、团队或捐赠者输入主机，以启用战术数据链参与者之间的目标及数据共享。

DOUBLE TAP / DOUBLE TAP
[空对空]向指定CONTACT发射两枚空空导弹，或每个GROUP中的每个CONTACT各发射两枚。

[system] DOWN [location, direction] / [系统] DOWN [位置/方向]

HVT / 高价值目标
具有重大战略、情报或军事价值的目标，优先于其他目标进行打击或监控。

IFE / 空中紧急状况
飞行过程中发生的危及飞机安全或人员生命的突发紧急事件。

IFR / 仪表飞行规则；飞行中报告
依仪表数据飞行的规则；或指飞行途中发出的状态与位置报告，视语境而定。

LKP / 最后已知位置
通信中断前记录到的目标或飞机的最后一个确切坐标点。

LL / 链路丢失
无人机与控制站之间的数据链中断，导致失去实时遥测或控制能力。

LZ / 着陆区
规划用于航空器降落、滑跑及后续地面操作的特定区域。

MAXORD / 最大弹药量
航空器在当前配置下能够携带的最大武器或炸弹数量。

PRI / 优先
表明该条目在通信队列或行动序列中具有最高处理等级。

RCVR / 受油机
正在接受或准备接受空中加油的航空器，配合加油机完成补给。

RON / 过夜驻留
因任务需要或天气原因，机组人员需在异地基地停留过夜。

ROZ / 限制行动区
因安全、政治或战术原因禁止或未授权进入的特定空域范围。

RP / 投放点
执行轰炸或空投任务时，武器或物资释放的具体空间位置。

RTB / 返航
指挥或决定航空器返回起始基地或指定安全机场的动作。

RTD / 归队执勤
人员或装备恢复待命状态，重新纳入可用作战力量序列。

SIPR / 机密路由器网络
用于传输保密级别信息的专用加密互联网协议路由网络。

SOF / 特种部队
执行特殊战术、侦察或非常规作战任务的精锐军事单位。

TOT / 预定攻击时间
多架次或多武器协同攻击时，要求同时命中目标的精确时刻。

TST / 时效性目标
出现时间短、窗口期窄的目标，需立即反应以捕捉或摧毁。

TX / 发射
指示或要求接收方发送信号、数据或信息。

UI / 唯一标识符
用于在系统中唯一识别特定实体、对象或会话的编码或代码。

VFR / 目视飞行规则
允许飞行员通过外部视觉参考操纵飞机的飞行规则和程序。

WX / 天气
指当前的气象状况或预报的大气环境条件。
