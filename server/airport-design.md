# 机场运行 v1

海湾国际机场BAY是虚构的游戏机场：双平行3600×45米跑道09L/27R与09R/27L，23米主滑行道A/B、端绕联络道C、等待点、G1–G6机位、停机坪、航站楼、塔台、标线和边灯。机场区域高度栅格整平到100米，渲染、后台规划和碰撞共用高度数据；布局不是现实机场工程审定成果。

|工作|负责方|实现|
|---|---|---|
|口语、呼号、机场与跑道意图|Qwen|结构化请求；不确定则澄清|
|跑道与滑行道实体校验|代码|校验存在性、完整左右编号、关闭状态|
|滑行道安排|代码|Dijkstra图搜索，可指定经由路线，图不含跑道穿越边|
|滑行速度、转弯、前方停车|代码|逐物理帧地面运动|
|跑道许可与间隔|代码|正反向共享独占锁、实际占用、越过等待线释放、90秒保守冷却|
|离场|代码|滑行→等待→进入对正→滑跑→抬轮→爬升|
|到场|代码|初始/中间进近→稳定最后进近→拉平→接地→滑跑→脱离→回机位|
|配置与保护|代码|可见起落架、襟翼/减速板阻力、中断起飞、跑道侵入/不稳定/无许可复飞|
|实体碰撞|代码|米制飞机近似盒体连续分离轴检测；飞机/飞机、飞机/机场建筑；忽略显示放大倍率|
|地形碰撞|代码|机身、翼尖和首尾扫掠采样|
|优先级或改跑道建议、异常解释|模型建议/玩家决定|程序再次核验，模型不逐帧驾驶也不创建许可|

左侧编队栏底部展开“机场运行”。“观察机场”进入机场视角；选择机位后“选中机地面出生”属于明确的场景布置操作。其余按钮执行正常连续运动。地面路线显示在地图上，事件日志显示各阶段许可。语音示例：“Alpha，沿A、A1滑行到09L跑道外等待”“Alpha，09L跑道起飞”“Alpha，09L跑道降落”。

严格模式下API机场任务与空中导航须分批，同机机场阶段命令逐条发送。放宽模式可补全本场跑道、合并滑行/等待/对正/起飞为一条离场流程，并在首选滑行道不可用时改走可达路线。补全记录放在execution.adjustments，实际改线记入机场通联。显式条件、未知机场/跑道、碰撞与跑道占用仍检查。单条起飞请求内置离场状态机，但通用条件调度仍待接入，不能假称“起飞后集合”等任务已排程。

验证：滑行路径、关闭、等待、独立进入/起飞许可、正反向占用、间隔、中断、最后进近、复飞、机位占用、实体碰撞、AI契约。实际地图高度场诊断从6500米出生完成进近、接地、脱离至G1；从G1完成离场爬升。记录`.game-server/airport-probe.json`。

范围：地面轮胎、轮载、气动配置阻力、起飞速度及进近阈值均为游戏简化参数，碰撞为近似体而非逐三角形破损。尚无真实ILS/导航台、动态风场/侧风着陆、各机型性能表、仪表进离场程序、真实尾流分类间隔、消防救援、旅客/机务/货运全流程、全球机场数据库。90秒冷却是本项目参数，不是现实通用尾流标准。对向滑行可能停车等待，尚无全场多机死锁求解器。这不是现实机场“一切流程”的完整仿真。

公开依据：[FAA Airport Design AC150/5300-13B](https://www.faa.gov/documentLibrary/media/Advisory_Circular/AC-150-5300-13B-Airport-Design-Chg1-w-errata.pdf)，[FAA AIM Airport Operations](https://www.faa.gov/air_traffic/publications/atpubs/aim_html/chap4_section_3.html)。采用公开布局和许可原则，不声明现实适航或军事条令认证。
