# 实时导弹与引导

已将本地 5 类、24 个导弹配置变体接入游戏更新循环。`sim/missiles.js` 积分飞行，`sim/weapons.js` 管理挂载、导引头准备、目标指定和发射；`World.step` 持续推进，暂停和倍速沿用游戏物理时钟。

## 在游戏里使用

1. 在场景设置选择空中出生，选中 F-16，点顶部“武器”。
2. “添加前方练习靶”会生成匀速靶机并打开雷达搜索。可以在“雷达”面板锁定靶机，或交给已接入的飞行员雷达任务判断。
3. 选择本机挂载。雷达弹等待本机稳定锁定和导引头准备；红外弹需从已发现目标中选择并点“指定目标 / 准备”，进入红外截获距离、角度后无需载机雷达照射。
4. 状态变成“可发射”后点“发射一枚”，或在指挥电台下令“Alpha，向 TGT 01 发射一枚 AIM-120”。电台继续遵循指挥员先播报、飞行员按实际通话接令的流程。
5. 在三维场景观察导弹和橙色弹道，在武器面板读取制导阶段、速度、马赫数、高度、过载、质量、推力和飞行时间。

默认 F-16 为混合演练挂载，五类各两枚，用于比较引导方式，未宣称符合真实载机挂架兼容性。F-86 默认没有导弹。展开“导弹演练配置”可装入任一目录内变体，两枚补弹是明确操作，本机有导弹在空时禁止调整；存档恢复不补弹。

## 飞行数据如何生效

| 数据 | 实际用途 |
| --- | --- |
| motorStages | 分段点火时间、推力、燃料质量线性消耗；包含 AIM-7P 的 0.25 秒延迟 |
| massKg / finalMassKg | 初始质量及燃尽质量，实时决定加速度 |
| dragCx、长与直径 | 简化阻力积分；密度与声速使用游戏既有大气模型 |
| reqAccelMax / propNavMult | 请求过载上限、比例导引系数；低动压削弱可用过载 |
| loftEnabled / loftElevation | 远距中段简化抬升，近距及主动末段退出 |
| guidanceDelaySec、warmupSec、workSec | 发射后控制延迟、发射前准备、导引头工作时长 |
| lockAngleDeg、gimbalAngleDeg、trackingRateDegSec | 发射截获角、视场限制和视线转速限制 |
| lifetimeSec、maxTravelM、speedLimitMps | 最大寿命、累计航程与源配置速度限制 |
| proximityFuse | 保险解除延迟、近炸半径；采用相对运动扫掠避免高速漏判 |

物理积分步长至多 1/120 秒，传感器按 20 Hz 更新。不是恒速追踪或按面板射程直接判定命中。近炸当前简化为命中范围内飞机损毁，不模拟破片及部件损伤。

## 三种引导确实不同

- **AIM-9M / PL-5EII**：红外寻的。距离、机头截获角、导引头转速及地形遮挡影响接获；载机雷达关闭不切断红外寻的。失去红外观测后短暂外推，随后失去控制并按物理飞行。
- **AIM-7P**：半主动雷达。发射前需本机稳定锁定，飞行中持续有效照射；掉锁后停止接收目标新位置。本地配置有惯导，故允许最后航迹外推，不能跟随隐藏的新机动。
- **AIM-120 / PL-12**：惯导及数据链中段、主动雷达末段。进入主动搜索区间依据最后收到的航迹估算，不读取隐藏的真实距离；接获后用弹上雷达的距离、视场、转速、杂波门及地形判断目标。关闭载机雷达会切断数据链，已建立的自主寻的不受其直接影响。

中段只接受本机当前有效雷达航迹；光学指定仅包含本机视场、距离和地形检查后发现的目标。模型上下文没有完整隐藏靶机列表。未知航迹不会自动判敌，当前自动战术尚不因导弹接入而启用。

WEAPONS HOLD/TIGHT/FREE 和 CEASE FIRE 只设置交战规则；不自动发射，也不撤回在空弹。HOLD 允许新的明确发射令，友机发射始终被拒绝。FOX 通报仍是通报。发射数量、弹量、地面状态、准备状态和目标有效性都在提交时重新校验，整批失败会回滚弹量、弹体、事件和序号。

## 工程近似与来源

这是一套使用战雷本地配置的游戏质点模型，未复现原引擎。阻力形式采用 [NASA 阻力方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/)，在本项目明确假定的 `length × diameter` 参考面积上使用源 `dragCx`，并加入项目定义的跨声速凸起和转弯能量损失；这不是已验证的战雷阻力曲线。低动压过载比例采用本项目 500m/s 海平面参考。没有把含义未验证的 CxK、翼面积乘子、舵面值和 PID 系数机械相乘。比例导引的背景可见 [NASA 目标寻的导航方法资料](https://ntrs.nasa.gov/citations/20090033671)。

未模拟红外热源强度/太阳干扰、箔条/热焰弹、完整 RCS/信号强度、天线伺服细节、多路径、六自由度弹体姿态、真实认证发射包线和不可逃逸区。面板射程保留为资料，不是必中距离。

## 维护和验证

本地源资料仍以 `data/flight-research/missiles/*.json` 为准。重新导入后运行 `node tools/build-missile-runtime.mjs`，生成自动加载的 `data/missile-runtime.js`，保留每个变体的来源 SHA256。测试会比较生成数据与源配置。

运行 `node --test tests/missile-flight.test.mjs`，覆盖全部变体装载与飞行、五类实算拦截、失锁、主动接获后独立寻的、不可见数据隔离、低动压/过载、燃尽滑行、寿命、航程、保险与扫掠引信、发射事务、指令编译、结果复述和存档恢复。
