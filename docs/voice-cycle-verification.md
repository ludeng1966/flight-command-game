# 机位出生与语音全流程验证（2026-11-07）

网页默认机位开局：Alpha在G1、Bravo在G2。机场栏可切换机位/空中出生并记住选择；切换执行模式不重置飞机。

Edge测试使用Windows慧慧合成语音注入浏览器虚拟麦克风，实际通过AudioWorklet录音、百炼ASR、Qwen3.7-Flash意图解析、本地程序执行与Qwen3.5-2B结果检查。未使用实体麦克风，未测扬声器实际听感；浏览器语音引擎完成各段播报。

三句实际转写：

1. 阿尔法，滑行到零九左跑道外等待。
2. 阿尔法，零九左跑道起飞，爬升至1300m。
3. 阿尔法，返航本场，在零九左跑道降落。

同一局依次通过滑行、跑道外等待、进入对正、起飞滑跑、爬升、返航进近、最后进近、接地、减速脱离、回机位。Alpha最终在G1停稳，Bravo始终在G2，均存活。加速验证直接推进同一物理内核，没有在阶段间重设飞机位置。

地图检查了滑行、起飞滑跑、爬升、最后进近与着陆滑跑的路线标签。通联区记录22条消息，区分玩家指挥台、BAY塔台和飞行员；三段指挥台播报及最终G1停车报告均由语音引擎完成。字幕在静音时仍保留。

测试中修复：滑行至等待点被模型拆成重复阶段时合并；返航降落接入着陆流程；阶段通话与玩家录音互斥；后台健康检查短暂失败不覆盖正在执行的任务状态。成功状态兼容“已执行”和“2B已检查”。

严格/放宽模式单独验证：严格模式要求完整跑道编号，缺省或不明确时澄清；放宽模式允许Flash补全已有机场跑道、合并滑行与起飞流程、对无法使用的首选滑行道重新规划。两种模式均保留实体存在性、显式条件、机位占用、跑道锁和碰撞检查。设置进入API上下文、能持久保存，切换不改变位置与速度。

全量168项自动化测试通过；严格/放宽开关另经Edge与真实Flash接口验证。
