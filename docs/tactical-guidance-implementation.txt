轮盘与持续方针接入说明（2026-11-12）

界面：game/tactical-wheel.js、tactical-wheel.css。R/T/C分别打开进攻方针、防御方针和直接机动轮盘。扇区选择有中心死区，松键发令；Esc、失焦、切换输入和页面隐藏取消。只捕获当前选中的己方飞机，在轮盘打开时冻结镜头输入，不改模拟速度。

状态：sim/tactical-guidance.js定义方针、直接机动与可传给模型的白名单。unit.tacticalGuidance保存offense/defense/revision、direct阶段和本地resume恢复任务。公开给模型的guidanceContext只提供方针、阶段及说明，不提供内部对象引用。save-state验证方针、恢复点与阶段数据，保存恢复不重放发射。

执行：game/tactical-director.js负责直接机动的规划、可行性校验、装订、复位及失效处理；通过TacticalCommands接入原输入与保存回调。server/tactical-maneuver.mjs接收结构化直接要求与当前本机上下文，由现有飞行员模型提出有限航路、速度、机动目的、原因及复位说明。阶段是planning/executing/recovering/completed，拒绝为unable，新命令接管为cancelled。正常任务的队列保留；复位回接下一固定目标后恢复未完成的后续航路。

模型：攻击、雷达、RWR使用相同GUIDANCE_RULES与tacticalGuidance上下文，方针指导风险及任务取舍，不能新增授权。直接机动期间攻击、雷达飞行判断和普通执行监督让出飞行控制。即时RWR安全控制保持可用。每次接令与阶段变化经原无线电队列报告双语原因、目的和恢复方案。

目录：六项表中进攻方案全部保留，另有BANZAI/SKATE/SHORT SKATE和战斗机扫荡，共10项；五项表中防御方针全部保留，另有区域防空、要点防空、高价值飞机保护、CAP、BARCAP，共10项；二十项直接机动分10+10两页，每页上限10，滚轮/Tab/页键可换盘。不能为适配轮盘容量删减或合并方案。标准简语依据公开的成员国多军种Brevity资料，六项中文方案是研究中提炼的游戏意图分类，不冒充北约正式分类。

授权：轮盘不额外增加发射数量或更换目标。双机方案记录共同方案编号、成员与本机角色，模型同时接收搭档的己方状态，不能读取敌方隐藏真值。分工/轮换方案中支援机不能自行发射；已有攻击授权的搭档可在原交战机无法继续或处于防御时接替角色，不创建新攻击授权。已有武器限制仍单独设置。具体取舍由飞行员模型结合已有任务、实测观测与武器支持状态判断，程序只执行已有能力并裁定真实结果。

资料：北约AJP-3.3 Edition C Version 1（2026）用于任务层级；已读取北约APP-7 Edition F Version 3（April 2020）正文并逐项核对简语；加拿大皇家空军公开条令用于扫荡及防空任务类别。不能把公开术语目录声称为现役北约全部战术与完整程序；不编造现实交战参数。逐项目录、依据和正文链接见tactical-wheel-catalog.txt。

验证：新增tactical-guidance单元测试覆盖方针存档、模型上下文、闭环复位、旧结果失效、明确转向、停火不撤销直接机动和接口验证。浏览器验证使用模拟上游，经过真实后台航路规划与飞行积分，不调用付费模型；覆盖三个轮盘、取消、恢复请求、重载与中英文和窄屏布局。真实云模型的判断质量与语音音色未在这轮自动化中实测。
