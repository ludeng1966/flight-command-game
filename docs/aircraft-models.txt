公开飞机模型接入（2026-11-08）

入口：设置 → 飞机外观，可为 ALPHA / BRAVO 分别选择 F-16、Su-27、J-11、Boeing 747-8I、Airbus A320-200。
对照页：game/aircraft-models.html。全部模式使用同一相机尺度，网格 10m；单机查看提供近距离外形检查。
当前机型选择会同步更换外观、气动、动力、质量与飞控限制。气动数据与近似说明见 docs/aircraft-physics.txt。J-11 使用 Su-27 基础外形与独立配色，但使用独立的战雷 J-11 气动数据，不冒充精确的 J-11 分型外形模型。

源模型：
F-16：NikolaiVChr/f16，GPL-2.0-or-later。Erik Hofman 及 authors.txt 中的贡献者。
Su-27 / J-11：xcvb85/Su-27，GPL-3.0。Yanes Bechir、FGUK 及 README 中的贡献者。
747-8I：JMaverick16/747-8，GPL-2.0。John Williams、Grupo FGBr、Gijs de Rooy 等，详见原 README。
A320-200 CFM：legoboyvdlp/A320-family，GPL-2.0。Josh Davidson、Jonathan Redpath、merspieler、Matthew Maring、Thorsten Herrmann、Semir Gebran。
assets/aircraft/sources/ 保留原始 AC3D 文件、许可、作者说明与按 Git blob SHA-1 锁定的来源清单。派生 JSON 模型保留各自原许可，不按项目 MIT 许可重新授权。

处理：提取外部机身、翼面、尾翼、发动机与独立起落架；移除内饰、贴纸、动画重复件与细小机械；丢弃大贴图，采用统一材质。
AC3D 层级变换与多边形绕序保持；使用 earcut 三角化、meshoptimizer 保边界减面，合并为少量按材质/起落架区分的网格。两款客机的每侧翼面用原始顶点的三维凸包封闭，合并不再动画的缝翼、襟翼和扰流板，避免静态翼面出现锯齿缺口。
按公开外形尺寸校准三轴，局部 -Z 机头、+Y 机背，1 单位 = 1m。减面后的实际包围尺寸见 assets/aircraft/build-report.json，最大尺寸误差控制在 0.5% 以内。
源 AC3D 的机头为 -X、机背为 +Y、右翼为 -Z；转换时同时校正前后和左右方向，保持绕序。以座舱在前、垂尾在后验证导出朝向，地图、缩略图与尾焰共用此坐标约定。
动态姿态由 three3d/aircraft-pose.js 将飞行内核当前机头/机背轴转为四元数：正滚转右机翼下沉，负滚转左机翼下沉；俯仰包含实际迎角，因此机头与速度方向可以不同。换向时跟随实际滚转变化，不提前套用目标滚转。tests/aircraft-pose.test.mjs 覆盖复合姿态、实际转弯、换向、地面航向与侧风。
地图缩略远景以F-16约42像素为基准，各机型不再按真实尺寸差等比放大；大型机最多比F-16大15%，选择圈保持统一尺寸。只有接近到F-16本身已清楚可见时，才平滑恢复真实米制比例；近距放大系数为1。气动、碰撞尺寸与同尺度对照页保留真实尺寸。
缩略图允许为图标独立取景，调用与地图完全相同的网格与材质。切换外观自动更新缩略图并保存到现有进度。

复建：node tools/fetch-aircraft-sources.mjs
安装构建依赖：npm install --prefix .game-server/model-tools meshoptimizer@1.3.0 earcut@3.2.4 three@0.186.0
转换：node tools/build-aircraft-models.mjs
构建依赖仅离线转换使用；浏览器不加载 AC3D、减面器、外部 CDN 或高分辨率贴图。
